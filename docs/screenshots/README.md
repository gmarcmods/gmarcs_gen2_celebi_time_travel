# Screenshot folder

Reference captures only. Naming: `<source>-<scene-key>-<nn>.png`
(e.g. `hgss-shrine-clearing-03.png`, `crystal-kurt-workshop-01.png`), one
numbered sequence per scene. Batch notes go in `NOTES.md` per source:
which scene each frame is, anything that screenshots cannot show
(actor facing, music, timing).

Subfolders: `hgss/`, `crystal/`.

For in-engine captures during later phases, follow `docs/README.md`'s
probe note: run a real driver from `gen1recomp/`, look at the images
before claiming anything, and only copy captures here after verifying.
